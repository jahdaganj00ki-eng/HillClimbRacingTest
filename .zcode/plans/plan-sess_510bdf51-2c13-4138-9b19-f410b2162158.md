# Hill Climb Racing Windows Clone - Updated Plan

## Key Requirements
- **Standalone Windows .exe** - runs without any external dependencies/installation
- **30 Tracks** across 5 difficulty tiers
- **GitHub Actions only** for builds (no local builds)
- **Modified mechanics**: Checkpoint respawn, no fuel, no time limit, 5+ vehicles with deep tuning

## Technology Stack
- **Engine**: Godot 4.3 (C# / .NET 8)
- **Export**: Single Windows executable (`HillClimbRacing.exe` + `HillClimbRacing.pck`)
- **CI/CD**: GitHub Actions (ubuntu-latest) → uploads `HillClimbRacing_Windows.zip`

## Vehicle Roster (6 Vehicles)
1. **Jeep** (Starter) - Balanced, RWD
2. **Pickup Truck** - Heavy, 4WD, high torque
3. **Sports Car** - Fast, RWD, low suspension
4. **Monster Truck** - Huge wheels, 4WD, high suspension
5. **Moon Buggy** - Low gravity specialist, 4WD
6. **Tank** (Unlockable) - Tracks instead of wheels, indestructible

## Tuning System (5 Categories × 10 Levels)
- **Engine**: Power +15%/level, Torque +12%/level
- **Suspension**: Travel +10%/level, Damping +8%/level
- **Tires**: Grip +10%/level, Width +5%/level
- **Weight**: Mass -8%/level, CoG lower -5%/level
- **Drivetrain**: 4WD split adjustment, Diff lock strength

## GitHub Actions Pipeline (`.github/workflows/build.yml`)
```yaml
name: Build Windows
on: [push, pull_request, workflow_dispatch]
jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Setup .NET 8
        uses: actions/setup-dotnet@v4
        with: { dotnet-version: '8.0.x' }
      - name: Setup Godot 4.3
        uses: firebelley/setup-godot@v2
        with: { version: '4.3', export-templates: true }
      - name: Restore & Build
        run: dotnet build HillClimbRacing.csproj -c Release
      - name: Export Windows
        run: godot --headless --export-release "Windows Desktop" build/HillClimbRacing.exe
      - name: Package
        run: cd build && zip -r ../HillClimbRacing_Windows.zip HillClimbRacing.exe HillClimbRacing.pck
      - name: Upload Artifact
        uses: actions/upload-artifact@v4
        with: { name: HillClimbRacing_Windows, path: HillClimbRacing_Windows.zip }
```
